## 草稿
### 摘要
Web应用程序扫描程序是流行且有效的渗透测试工具，通过探索和与用户界面交互来自动检测漏洞。尽管它们有效，但由于对工作流程的了解有限，这些扫描仪仍难以在现代web应用程序中发现更深层的状态。本研究提出Task-driven Vulnerability Agent，一款具备任务驱动的Web应用渗透测试程序，它利用大语言模型来自主执行任务和工作流。该 Agent 以任务驱动的方式解析网页结构与交互语义，自动生成并执行多步任务，以触达传统黑盒扫描难以覆盖的深层输入点。在检测阶段，系统内置多个相互独立的漏洞发现子 Agent，分别针对不同类型的安全风险构建语境自适应的模糊引擎。各引擎在输入建模、变异策略与判定逻辑上融合了近年来安全研究中的先进思路，实现对跨站请求伪造、服务器端模板注入、SQL 注入、服务端请求伪造及跨站脚本等典型漏洞的自动探测。本文在多个具有代表性的 Web 应用上进行了系统评估，并在实验章节中对不同漏洞类型的检测效果进行了横向对照与性能分析。结果显示，任务驱动与语义感知相结合的多引擎体系能够显著扩展检测覆盖面，提高多类漏洞的发现率与自动化水平，为智能化 Web 安全测试提供了一种可复现的通用框架。
