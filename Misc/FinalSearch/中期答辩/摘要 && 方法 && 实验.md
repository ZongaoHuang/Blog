| ---- | ----- | ----- | ------- | -------------------- |

| 后端   | 注入    | SSTI  | MVC     |                      |
|      | 注入    | SQL注入 | 数据库     |                      |
|      | 不安全配置 | XXE   | XML     |                      |
|      | 认证缺陷  | 请求走私  | Request |                      |
|      | SSRF  | SSRF  | Request |                      |
